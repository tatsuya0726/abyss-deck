# 横画面イベント修正（2026-09-25）

## 変更

- `responsive-events.css` を `responsive-shell.js` から最後に読み込み、イベントの横画面専用指定を分離。
- メニュー用の余白とメニュー自身の高さを二重に取らない。上端のメニュー1段と残りのパネル領域を明示。
- パネル外枠を実表示高に収め、長い本文・選択肢は内部スクロール。縦3択、左のイラスト、ふりがなを維持。
- 文字の自動拡大を横画面だけ抑制。レリック効果見出しをインライン化し、余白と文字サイズを整理。
- 上下の座標補正・最近傍ボタン検索・代理クリックを削除。通常のクリックを使い、イベントの枠外タップとスワイプ由来の誤クリックだけ拒否する。
- 縦画面・ゲームルール・セーブ形式・公開URLは変更しない。

## キャッシュと公開

`tools/prepare-pages.cjs` が公開直前の `dist/index.html` と `dist/game.html` の `responsive-shell.js?v=` をコミットSHAへ置き換える。リポジトリ側HTMLは変えず、配信用成果物の参照を確実に更新する。公開ワークフローの権限と公開範囲は従来どおり。

## 検証

- 既存 `tools/verify-project.cjs`: ファイル参照・構文・空ファイルの問題なし。
- Chromiumのオフライン描画テスト: 844x390、852x393、667x375、568x320、844x300、1536x706、1920x1080。ふりがな付きで外枠が収まること、短い画面では最後の選択肢まで内部スクロールできることを確認。
- 境界近くの第2・第3選択肢、隙間、無効ボタン、スワイプ、縦横切り替え、実表示高の変化を確認。
- 縦画面は新スタイルの有無で同じレイアウト。iPhone実機Safariは未検証。
